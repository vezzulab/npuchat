Why NPU ChatPor qué NPU Chat

Put the chip you're not using to work Pon a trabajar el chip que no estás usando

Most local AI apps on Linux (Ollama, llama.cpp, LM Studio) run models on the CPU or GPU. Ryzen AI laptops also have an NPU, a chip built for AI that usually sits idle. NPU Chat runs the model there. La mayoría de apps de IA local en Linux (Ollama, llama.cpp, LM Studio) corren los modelos en la CPU o la GPU. Las laptops Ryzen AI también tienen una NPU, un chip hecho para IA que normalmente no se usa. NPU Chat corre el modelo ahí.

InstallInstalar

Up and running in three stepsListo en tres pasos

You need an AMD Ryzen AI 300/400 series laptop (XDNA 2 NPU) with Linux kernel 7.0 or newer. Necesitas una laptop AMD Ryzen AI serie 300/400 (NPU XDNA 2) con kernel de Linux 7.0 o más nuevo.

Install FastFlowLM (the NPU engine)Instala FastFlowLM (el motor de la NPU)

On Fedora:En Fedora:

sudo dnf copr enable alessandrolattao/fastflowlm
sudo dnf install --exclude=xdna-driver-dkms fastflowlm
sudo flm-fetch-kernels

Other distros: see the FastFlowLM guide.Otras distribuciones: consulta la guía de FastFlowLM.

Download and run NPU ChatDescarga y abre NPU Chat

chmod +x NPU-Chat-x86_64.AppImage
./NPU-Chat-x86_64.AppImage

Pick a model and chatElige un modelo y conversa

Open the model menu, download one that fits your laptop, and start typing.Abre el menú de modelos, descarga uno que quepa en tu laptop y empieza a escribir.

“The NPU needs a system setting to work”«La NPU necesita un ajuste del sistema para funcionar»

systemd caps locked memory at 8 MB, and the NPU needs more to load a model. Run this once, then reboot:systemd limita la memoria fija a 8 MB y la NPU necesita más para cargar un modelo. Ejecuta esto una vez y reinicia:

sudo mkdir -p /etc/systemd/system/user@.service.d /etc/systemd/user.conf.d
printf '[Service]\nLimitMEMLOCK=infinity\n' | sudo tee /etc/systemd/system/user@.service.d/memlock.conf
printf '[Manager]\nDefaultLimitMEMLOCK=infinity\n' | sudo tee /etc/systemd/user.conf.d/memlock.conf
